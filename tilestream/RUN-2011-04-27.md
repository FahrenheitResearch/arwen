# 2011-04-27 Super Outbreak — ArWen, streamed out of core

**What these images are.** A convection-allowing numerical weather forecast of
27 April 2011 — the Super Outbreak, 216 tornadoes across the southeastern
United States — produced by ArWen (gpuwm) and rendered by ArWen's own
production renderer, `gpuwm render --engine rust`.

**What they are not.** They are not radar. The reflectivity field is
`REFL_10CM`, a *model* diagnostic computed by `gpuwm.core.refl` from the
model's own hydrometeor species, and the plotted quantity is its column
maximum. The updraft helicity is likewise a model diagnostic. Nothing on
these panels is an observation.

**Read the last section before using these for anything.** The run was cut
short by a machine failure and did not reach the afternoon tornado peak.

## The forecast

| | |
|---|---|
| Event | 2011-04-27 Super Outbreak (MS / AL / TN) |
| Initial condition | ERA5 reanalysis, 2011-04-27 12:00 UTC |
| Lateral boundaries | ERA5, real 3-hourly cadence (12, 15, 18, 21, 00 UTC) |
| Domain | 960 x 960 x 49 = **45,158,400 cells** (921,600 columns) |
| Grid spacing | dx = 3 km — **2880 km x 2880 km**, lat 20.8–47.5 N, lon 106.8–69.2 W |
| Time step | 15 s |
| Microphysics | Morrison two-moment (mp10) |
| PBL / surface | MYNN 2.5 + Noah-MP, called every step |
| Radiation | RTE-RRTMGP, 12 min cadence — fires 1–2 times per 60-step sweep |
| Cumulus | **none.** At 3 km convection is resolved, not parameterised; operational HRRR is also 3 km and also runs no cumulus scheme. |
| Execution | out-of-core tiled stream (`tilestream.driver.run_tiled`), `write_mode="ring"`, `nbuffers=2`, non-periodic |
| Decomposition | 16 tiles of 240 x 240, halo 20 (dependency radius 16 + boundary width 4), 280 x 280 compute windows, 1.361x redundancy |
| Machine | one NVIDIA RTX 4090, 23.52 GiB usable |

### The domain does not fit on the card

This is the point of the exercise, and it was measured on the same 4090 that
ran the forecast, not asserted:

* the **row-slab ingest** prepared 960 x 960 x 49 at a 15.55 GiB device
  high-water (18,116 B per mass cell) — it fits;
* a **resident full-domain `dycore.step`** of the same state then refused:
  `cupy.cuda.memory.OutOfMemoryError` allocating 180,633,600 bytes (one
  960 x 960 x 49 float32 field) after **24,429,406,208 bytes**, inside
  RRTMGP's `hydrometeor_paths`, on the first radiation call;
* the **streamed** forecast peaked at **16.6–17.8 GiB**, because only two
  280 x 280 x 49 tile buffers are ever resident. The domain itself lives in
  **9.72 GiB of pinned host RAM** (231.2 B per cell) plus 0.72 GiB of
  geography and 1.32 GiB of windowed lateral-boundary tables.

## The files

* `sequence/` — column-maximum simulated reflectivity, the same with 2–5 km
  updraft helicity overlaid, updraft helicity alone, and surface-based CAPE;
  whole domain, one set per forecast hour from 12:30 UTC.
* `environment-and-synoptic/` — 500 mb heights and winds at initialisation
  (the negatively-tilted trough and the 100+ kt jet streak that made the day),
  and the 12 UTC surface-based CAPE field.
* `full-product-catalog-1630z/` — every product the rust renderer's catalog
  can prove out of one frame (16:30 UTC): the 200–850 mb isobaric families,
  the severe suite, surface fields, 1 km and composite reflectivity.

Filenames carry the domain and resolution token (`d01-3km`), the
initialisation, the lead and the valid time, all read from each file's own
attributes.

## What this run did NOT do — read this

The forecast was **cut off at t+5.75 h (valid 17:45 UTC)** when the rented
machine became unreachable at about 19:40 UTC wall clock; ICMP stopped and the
SSH port began refusing connections. Frames may exist on that machine's disk
past the last one confirmed in the log, but they are not here.

**Therefore this run did not reach the tornado outbreak's peak.** The observed
peak was 19–23 UTC: 15 tornado reports at 19 UTC, 42 at 20 UTC, 29 at 21 UTC,
24 at 22 UTC, 28 at 23 UTC, concentrated in Alabama and Mississippi. The
Hackleburg–Phil Campbell EF5 was on the ground from 20:05 UTC and the
Tuscaloosa–Birmingham EF4 from 21:43 UTC. **None of that is in these images.**

What the run DID produce, and where it agrees with the record:

* the morning and midday convective rounds initiated in the right places —
  Arkansas/Missouri and a band through northern Mississippi into northern
  Alabama and Tennessee, which is where the 27 April morning QLCS and the
  midday second round actually were;
* by 16:30 UTC a coherent broken line across northern MS → northern AL → TN
  with embedded rotating cells, plus the warm-front MCS over the Great Lakes
  and dryline convection in the Plains — all features of that day;
* peak 2–5 km updraft helicity of 200–440 m² s⁻² in the MS/AL corridor by
  15:30–17:45 UTC. That is supercell-grade rotation in the right place at a
  plausible time, but it is **not** evidence about the violent tornadic
  supercells of the late afternoon, which this run never reached.

Anyone extending this run should note that the 12 UTC ERA5 initial state has
essentially no surface-based CAPE over land in Alabama and Mississippi (see
`environment-and-synoptic/`), so everything convective here was generated by
the model during the integration rather than inherited from the analysis.
