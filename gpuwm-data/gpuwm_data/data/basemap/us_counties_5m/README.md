US county cartographic boundaries used by `wx-render`.

Included layer:
- `cb_2023_us_county_5m` (1:5,000,000 generalized county boundaries,
  2023 vintage), carried as `.shp` / `.shx` / `.prj` only; the `.dbf`
  attribute table is not needed by the renderer and is not shipped.

Source:
- https://www.census.gov/geographies/mapping-files/time-series/geo/cartographic-boundary.html
- https://www2.census.gov/geo/tiger/GENZ2023/shp/cb_2023_us_county_5m.zip
