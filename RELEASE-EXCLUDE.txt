# public release snapshot.

# These paths are development-campaign records -- lead/controller
# handoffs, phase plans, machine-specific runbooks -- several of which
# bake a per-user home directory into a shipped file, contradicting the
# release builder's own "no developer-specific absolute paths" bar and
# confusing a stranger about what the product is (acceptance finding
# F13, PRODUCT-V1-ACCEPTANCE-20260729).
#
# This file is an exclusion manifest for the snapshot/release builders;
# nothing listed here is deleted from the development tree.  One path or
# glob per line, relative to the repository root; lines starting with
# '#' are comments.
#
# Exclusion is only half the job.  A manifest cannot name the file that
# grows a machine path next, so work/build_release_snapshot.py scans
# every staged text file for one and FAILs the build; see
# MACHINE_PATH_MARKERS there.  Adding a path here is the escape hatch
# for a file that is genuinely not worth scrubbing -- never the first
# resort.
