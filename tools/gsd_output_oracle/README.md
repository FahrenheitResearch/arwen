# Pinned GSD hail oracle

Download `phys/module_diag_gsd.F` from NOAA-EMC/HRRR commit
`40ee6058c2fc6624cbfbbe8cf1c20c59e6a45827`, under
`sorc/hrrr_wrfarw.fd/WRFV3.9/`. Its SHA-256 is frozen beside the vectors.

Run `python tools/gsd_output_oracle/extract.py SOURCE_DIR OUTPUT_DIR`, then
compile the generated `main.f90` with:

```
gfortran -O0 -ffp-contract=off -fno-fast-math -o oracle main.f90
./oracle > vectors.txt
```

The receipt was generated using local WSL gfortran. It contains the native
50-bin diameter/width binary64 words and seven native hail-diameter
float32 words, not outputs regenerated by the CUDA implementation.
