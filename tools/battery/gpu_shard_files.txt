# The release battery's GPU pytest shard.
#
# WHAT THIS IS
#   The set of test files the battery runs on a CUDA device at a cut.  It is
#   the third leg, beside tools/battery/stage1_files.txt (CPU pytest) and
#   tools/battery/cargo_gates.txt (Rust).
#
# WHY IT EXISTS
#   Gap G2 of the 2026-08-13 test-estate audit: THERE WAS NO GPU PYTEST LEG
#   AT ALL.  stage1_files.txt is CPU by construction, cargo_gates.txt is
#   Rust, tiles_gates.txt names `python -m tilestream.*` modules.  No file
#   anywhere named a GPU pytest shard, so the entire WRF-parity dycore ran
#   on no list -- 6th-order diffusion including its boundary faces, both
#   Smagorinsky closures, open and specified lateral boundaries, the
#   acoustic solver, the mapped mass closure, the TKE budget.  The audit
#   measured 389 of 1,258 in-scope core tests (31%) skipping on CPU, with
#   these files at 100%.
#
#   Consequences are not hypothetical.  tests/test_wrfout_conformance.py is
#   18 of 18 skipped on CPU, and its own docstring says every OTHER wrfout
#   test is self-consistency while it is the only file that judges a gpuwm
#   wrfout with a real WRF reader.  It is the file that would catch the
#   ISNOWXY-class miss, and a CPU-only gate never asks it.
#
# WHO CONSUMES IT
#   The GPU leg of the per-assembly queue scripts, parsed exactly as the
#   stage-1 list is:
#
#     $gpushard = @(Get-Content (Join-Path $CUT 'tools/battery/gpu_shard_files.txt') |
#         ForEach-Object { $_.Trim() } | Where-Object { $_ -and -not $_.StartsWith('#') })
#
#   It runs on a DESIGNATED GPU NODE (node-1 class: a 16 GB sm_120 card, a
#   CUDA toolkit whose headers CuPy can compile against, and a cupy wheel
#   matching the box's CUDA major -- see the rental playbook).  It does NOT
#   run on Drew's desktop card: GPU authorization is a state Drew sets, and
#   a release leg must not assume it.
#
#   Run it with GPUWM_NO_LOCAL_GPU UNSET.  That variable is what makes the
#   CPU legs honest; setting it here would skip the entire shard and report
#   green, which is the exact class of defect this file was created to end.
#
# FORMAT
#   One repository-relative path per line, forward slashes.  Blank lines and
#   lines whose first non-space character is `#` are ignored.
#
# AMENDMENT DISCIPLINE
#   As tools/battery/stage1_files.txt: an addition carries its REASON
#   inline, on the lines above it, naming the task or the incident.  A
#   removal is an argument made in the commit, not a tidy-up.
#   tests/test_gpu_shard_manifest.py is the gate -- it checks every path
#   exists, rejects duplicates, and pins the property that earns an entry a
#   place here: that the file really is GPU-bound, so a CPU leg cannot be
#   mistaken for coverage of it.
#
# SHARD 1 is below and is the per-cut leg.  SHARD 2 (the GF cumulus family)
# is listed at the bottom and is weekly, on the audit's reasoning that
# frozen bit-exact oracle ports carry the mass and almost none of the
# defects.

# ---------------------------------------------------------------------------
# SHARD 1d: the streamed production clock, ARMED.
#
# `pytestmark = requires_gpu` on the whole module, so it is 100% skipped on
# a CPU box and belongs here by the same rule as 1a.
#
# It earns the per-cut leg rather than the weekly one because of WHAT it
# asserts.  The three bound roads -- streamed parent, streamed child,
# per-domain [tiles] -- meet one carrier inventory here, and the property
# is that the production clock is ARMED on each of them.  A streamed run
# whose clock never arms does not crash: it produces a forecast, and the
# lateral boundaries lag it by a timestep (task #219, where the gate suite
# was structurally blind to exactly this).  Silent-wrong-answer coverage is
# the last thing to run weekly.
#
# Registered at the 2.3.0 round-2 assembly.  lane/reach-223 shipped the
# file and did not list it, so between the lane landing and this line the
# test existed and no leg ran it -- the "a gate nobody can enumerate"
# failure tools/battery/tiles_gates.txt names in its own header.
# ---------------------------------------------------------------------------

# every cut.
#

# separate so a runner cannot silently promote one into the per-cut leg.
