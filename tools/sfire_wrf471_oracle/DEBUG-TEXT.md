The debug writer is anchored to WRF 4.7.1 module_fr_fire_util.F SHA-256 ab9499f12b305257fd62a0c76f299ee308b7fabc98c6fae073ba25f132ec8d27, routine write_array_m3. The extraction wraps that unmodified routine with serial process services and mesh checks. The native harness generates default-REAL values and exports their raw words in k, j, i order.

The Rust ABI gpuwm_static_sfire_debug_array accepts UTF-8 JSON followed by a contiguous f32 pointer and word count. Metadata contains name, path (an existing output directory), shape [nz, ny, nx], bounds [its, ite, jts, jte, kts, kte] and a positive step. Rust writes name_00000001.txt with six default-REAL bound records, then the values. Every record uses E20.12 and one newline. Name components and inclusive shape agreement are validated before opening a file.

The permanent fixtures contain 4,121 words in three arrays. Compiled WRF and the built native ABI produced identical 86,919 text bytes, including signed zero, approximately 1e-38, the minimum subnormal and normal values, maximum finite values, infinities, NaNs and integer-to-REAL header rounding. receipts/debug-text.json binds the native library, compiler, inputs and outputs. Rust unit tests read the same immutable native words and expected text.

Two original defects are corrected by default. WRF's I8.8 filename descriptor writes stars after step 99,999,999, so different later steps can overwrite one file. Rust retains the complete number, with a minimum of eight digits. WRF's implied DO overflows when a loop ends at INT32_MAX and the compiled control exits with SIGSEGV. Rust iterates the validated finite slice instead. Its maximum-bound header has the same REAL rounding as the valid INT32_MAX-1 native control. Both corrections preserve the unaffected text bytes and are listed separately from parity checks.

To reproduce, build the static-fields shared library, then run build_debug.sh OWNED_ORACLE_DIRECTORY and grade_debug.py --reference OWNED_ORACLE_DIRECTORY --library BUILT_LIBRARY --output OWNED_COMPARISON_DIRECTORY. The deliberate native overflow reproduction is bounded to five seconds and disables core files. These controls use no GPU. The runtime chooses first N steps and every Nth step when fire_print_file is positive; interval selection belongs to the coupled driver.
