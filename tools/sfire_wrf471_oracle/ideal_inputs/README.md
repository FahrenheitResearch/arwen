Native formatted initializer inputs are decoded in Rust. Python sends file and shape metadata, allocates float32 buffers and keeps their ownership. It performs no field parsing, value conversion or interpolation.

The source-pinned native controls compile the unchanged `read_array_2d_real` and `read_sounding` routines with serial execution and bounds/message service stubs. Two arrays and eight sounding fields supply 30 default-REAL words. The recorded control grades all 30 words bit-identically, including non-square transposition, split records, discarded record tails, repeat notation, D and implicit exponents, signed zero, tiny values and the largest finite value. Rust unit controls cover required-record EOF, native partial sounding EOF, undefined null values and REAL overflow. The native initializer remains the reference for physical sounding and landuse calculations.

Run `build.sh OWNED_BUILD PINNED_MODULE_INITIALIZE_FIRE` then `grade.py --build OWNED_BUILD --landuse LANDUSE.TBL` with the newly built static-fields library. `GPUWM_STATIC_BRIDGE` names that library. `PYTHON` names the interpreter used by the build script. The fixture and reference source hashes are recorded in the receipt.

All nine native fixed-file inputs are REAL. The first record gives ni,nj. Each following READ fills one x column with j ascending, may span records, and discards excess values on its final record. Rust returns contiguous arrays shaped `(nj, ni)`. Atmospheric files include the terminal row and column; fine files include the native terminal refinement extension. Fuel mode 2 reads `input_fc`; moisture mode 2 reads `input_fmc_g`. Class moisture and perimeter history have no native text read here and use the separate WRF input door.

Sounding pressure remains mb, temperature remains potential temperature in K, mixing ratio remains g/kg and winds remain m/s. The header mixing ratio is retained; native `get_sounding` uses the first profile mixing ratio for surface density. A partial final profile is discarded as the native EOF branch does. More than 1000 complete levels are refused before the original routine could overwrite its arrays. Missing values and slash/null records are refused because they leave required operands undefined.

LANDUSE.TBL keeps its raw seven REAL columns, with `(season, category, column)` shape. Category numbering is checked exactly. Missing sections return an empty table with `found=false`, preserving the native table-not-used disposition. The GPU landuse initializer owns percentages, centimeter conversion, seasonal selection and the native reuse of final-season SCFX. Raw table parsing is distinct from the complete original `landuse_init` physical consumer qualification.

The native routine's 128-character diagnostic buffer cannot hold long absolute filenames. The harness uses the same fixed basename/cwd calls as the original initializer. Rust accepts the explicit directory without that diagnostic-buffer failure. No native weather initializer or model forecast is replaced by these raw-text controls.
